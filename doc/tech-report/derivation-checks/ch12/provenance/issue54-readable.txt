## Rules for every fix

1. One PR per item, into `fix/thermo-20261019` of this fork (never into `main`, never upstream).
2. The PR adds an in-tree test (pytest or gtest, registered with ctest). It FAILS on `0d9f67f` and PASSES with the fix. Quote both runs in the PR body.
3. Minimal diff, and no change of behaviour outside the item.
4. Report CPU results and, where the code has a CUDA path, CUDA results.
5. Rerun the item's evidence script below and quote its RED line before and after the fix.
6. Cross-review by another bot for BIG items only. None of the rows below is marked BIG today.
